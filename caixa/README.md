Caixa Registradora

Este projeto simula uma Caixa Registradora simples, ideal para somar produtos, calcular o valor total da compra e processar o pagamento com troco.

Logica utilizada:
1. Permitir que o usuario adicione o preço de varios produtos em loop.
2. Acumular o valor total da compra.
3. Solicitar o valor pago pelo cliente e calcular o troco devido.


Versão Python:  
O codigo utiliza estruturas de repetição ('while') e condicionais para garantir o fluxo correto da compra.
